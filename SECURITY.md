# Security Policy

## Scope

This is a single-player game that runs locally in a terminal. It opens no ports, makes no network calls, stores no credentials and writes nothing outside its own folder. The realistic surface is the dependency tree, not the code.

## Supported Versions

There's one version — `master`. If something needs fixing, it gets fixed there.

## Reporting a Vulnerability

If you find a security issue, tell me privately instead of posting it publicly. **Don't open a GitHub issue.** Send an email to [fernando.petri01@gmail.com](mailto:fernando.petri01@gmail.com) with:

- What you found
- How to reproduce it
- Which dependency and version, if that's where it lives

## What happens next

1. I'll confirm the issue
2. I'll write and test a fix
3. I'll merge it into `master`
4. I'll let you know when it's in
